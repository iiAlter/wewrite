# 溯源标注规范（古典内容版）

## 证据分级

| 级别 | 名称 | 来源示例 | 使用场景 |
|------|------|----------|----------|
| A级 | 权威工具书 | 古诗词网 gushiwen.cn、汉典 zdic.net、诗词名句网 | 诗句原文、字词释义、典故出处 |
| B级 | 学术资料 | 中华书局出版物、维基百科中文词条（争议项除外） | 历史背景、诗人履历、文学史地位 |
| C级 | AI知识补充 | 模型训练语料 | 仅在A/B级信源不足时使用，标注"（AI知识补充）" |

## 禁用表达（无来源声明）
- "据说"、"相传"、"诗人曾经"
- 关键数字无来源（如"他活了82岁"必须有来源支撑）
- 争议性事实无标注

## 标注格式规范

### 字词释义标注
`【注释①】床（chuáng）：指井栏，古代井边围栏叫床。来源：汉典 zdic.net`

### 典故出处标注
`【典故②】"折腰"出自《晋书·陶潜传》："郡遣督邮至县，吏白应束带见之，潜叹曰：'吾不能为五斗米折腰'"`

### 历史事实标注
`【背景③】开元二十四年（736年），王维时任右拾遗。来源：《旧唐书·王维传》`

### AI知识补充标注（最后手段）
`（AI知识补充：此字在金文中已出现，来源待考）`

## 查证优先顺序
1. 古诗词网（so.gushiwen.cn）— 诗词正文、注释、赏析
2. 汉典（zdic.net）— 字词释义、字形演变
3. 诗词名句网（shijimingju.com）— 名句查询、作者介绍
4. 维基百科 — 诗人履历、历史背景（争议项需交叉验证）
5. AI知识补充 — 仅作为最后手段

## 查证脚本使用
使用 `research_classical.py` 脚本自动查询权威信源：
```bash
python3 ~/.mioclaw/skills/wewrite/scripts/research_classical.py --type poetry --title "静夜思" --author "李白"
python3 ~/.mioclaw/skills/wewrite/scripts/research_classical.py --type character --char "㐂"
```
